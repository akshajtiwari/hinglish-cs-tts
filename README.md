# Hinglish Code-Switched TTS

Research project on Hindi-English code-switched text-to-speech, started 2026-09-23.

**Working title:** *Natural Switches Are Not Seamless: A Switch-Localized, Human-Calibrated Metric for Code-Switched TTS, with a Hinglish Case Study.*

**Problem in one line:** Hinglish TTS gets the words right but sounds wrong at the exact moment it switches between Hindi and English, and nobody measures that moment. We build a score that checks whether a switch sounds like a real bilingual speaker, then use it to test what training on real Hinglish conversation fixes and what it costs.

All research documents are in [`docs/`](docs/README.md).
